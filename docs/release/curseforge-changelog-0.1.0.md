# Tetra Apothic Link 0.1.0

Initial release for Minecraft 1.20.1 Forge.

- Added modular Tetra tool and Tetrawear armor categories for Apotheosis.
- Added light/heavy armor affixes, gems, and special abilities.
- Added four Arcane Capacity Inscription tiers with staged Apotheosis infusion scrolls.
- Added optional Create: Enchantment Industry overload handling and the Enchantment Tuner.
- Added server configuration, datapack rule overrides, diagnostics, and client synchronization.
- Added English and Simplified Chinese localization.
- Added an original monochrome Tetra-style pixel-art project icon.

Development verification includes automated tests, a clean build, and a successful Holosphere module-material page regression check with Tetra Insight 0.1.6.
