# Tetra Apothic Link 0.2.0-alpha.1

Experimental alpha for Minecraft 1.20.1 / Forge / Java 17. Prepared for upload; this document does not indicate that a CurseForge file has been uploaded or published.

## English

- **Tetrawear is now optional. You can omit it.** Tetra tools, ranged weapons, Apotheosis affixes/gems/reforging, Arcane Capacity progression, and the Ascension Table remain available without Tetrawear. Its armor and energy integration activates only when installed.
- Added an experimental **Ascension Table** that reuses Apotheosis' enchanting-screen layout, bookshelf statistics, experience costs, and native Quanta/rectification/Arcana algorithms. No extra rectification bar was added.
- Added five media: **Structural Ascension, Material Exaltation, Material Attenuation, Unstable Overlimit, and Stabilizing**. They raise integrity supply, tune material primary/secondary/tertiary contributions, allow unstable overlimit, and stabilize previously acquired power.
- Ascension binds to the **whole equipment item**, not removable modules; supported replacement/reforging preserves it. Salvaged components do not carry the upgrade.
- Unstable overlimit is currently **handheld-only**, permits up to 60 integrity deficit, and uses native Tetra Winded, Vexing, and Infested effects rather than Minecraft curse enchantments.
- Added persistence, isolation, and developer runtime checks; retained the existing tool/armor, gem, inscription, and optional Create: Enchantment Industry integrations.

**Alpha notice:** balance values and recipes are experimental; visuals currently reuse vanilla models/textures. Back up your world before testing. This is not a stable release.

## 中文

- **Tetrawear 现为可选依赖，可以直接不安装。** 不安装时仍保留 Tetra 工具、弓弩、神化词缀／宝石／重铸、魔力刻印成长线与升格台；安装后才额外启用其护甲和精力联动。
- 新增实验性**升格台**，沿用神化附魔界面布局、书架属性、经验成本，以及量子化／校准／阿卡那原生算法，不新增校准属性栏。
- 新增**结构升格、材质升华、材质压缩、不稳超限、稳定化**五种媒介，用于提高完整度、调整材料主值／副值／第三值、超限安装与后续稳定化。
- 升格**绑定整件装备而非可拆模块**；受支持的物品转换和重铸保留强化，回收部件不带走收益。
- 不稳超限目前**仅限手持装备**，最多超支 60 完整度，代价采用 Tetra 原生疲乏、恼鬼、虫蚀失稳效果，不是 Minecraft 诅咒附魔。
- 补充持久化、隔离及开发运行验证，保留既有工具／护甲、宝石、魔力刻印与可选 CEI 联动。

**Alpha 提醒：**数值和配方仍在试验阶段，模型与纹理暂时复用原版资源；请先备份世界测试。本版本不是稳定版。
